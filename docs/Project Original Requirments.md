Project Overview
In this project, you will work in teams of 5-7 students to design a complete software
system. The goal is to apply concepts from Requirements Engineering and System Modeling
(UML) to a real-world problem.
Each team will choose one of the following project topics:

1. Hospital Management System
2. Online Food Delivery System
3. University Course Registration System
4. Smart Parking System
5. E-commerce system
   Project Deadline is 6/5
   You need to identify System Description containing: - Project Title - Problem Description - System Objectives - Stakeholders -WBS of the project
   Your System must include Requirements Engineering Process
   Functional Requirements (10–12)
   Non-Functional Requirements (5–7)
   User vs System Requirements must be identified and written in both.
   Requirements Analysis (ambiguity & conflicts that you find in your case)
   Models That Must Be Delivered (indicating the whole system): - - - - - -
   Use Case Diagram  
   Context Diagram
   Activity Diagram
   GANTT chart
   Pert diagram
   State Machine Diagram (BONUS)
   Explain why each model is used and how they connect
